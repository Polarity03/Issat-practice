# Sub-Task 1: Investigating GitHub and GitLab

## Introduction

GitHub and GitLab are web-based platforms used by software developers to store, manage and collaborate on software projects. Both platforms use **Git**, a distributed version control system, to keep track of changes made to source code.

GitHub and GitLab provide repositories where developers can store their projects, work together with other developers and manage the software development process. However, they differ in their features, licensing models and approaches to software development.

---

## 1. GitHub

[GitHub Official Website](https://github.com/about)

GitHub is a development platform that allows developers and organisations to host software projects and collaborate on code. It provides tools for version control, project management, code review, automation and community collaboration.

### Key Features of GitHub

#### 1. Repositories

A repository is a storage location for a software project. It can contain source code, documentation and other project files. Developers can use repositories to manage and collaborate on their projects.

#### 2. Pull Requests

Pull requests allow developers to propose changes to a project. Other developers can review the changes, provide comments and approve them before they are merged into the main project.

#### 3. GitHub Actions

GitHub Actions is an automation and CI/CD feature. It allows developers to automatically build, test and deploy software using workflows.

### Other GitHub Features

- GitHub Issues for reporting bugs and managing tasks.
- GitHub Discussions for questions and community discussions.
- GitHub Projects for planning and tracking work.
- GitHub Codespaces for cloud-based development environments.
- GitHub Packages for hosting software packages.

---

## 2. GitLab

[GitLab Official Website](https://about.gitlab.com/)

GitLab is a DevSecOps platform that provides tools for different stages of software development. It provides source-code management, CI/CD, security, package management and deployment features within one platform.

### Key Features of GitLab

#### 1. Git Repositories

GitLab provides Git-based repositories where developers can store, manage and collaborate on source code. Developers can create branches and merge changes while working on the same project.

#### 2. GitLab CI/CD

GitLab includes CI/CD tools that can automatically build, test and deploy applications. This allows developers to automate parts of the software development process.

#### 3. DevSecOps and Security Tools

GitLab integrates security into the software development lifecycle. Its security features include Static Application Security Testing (SAST), Dynamic Application Security Testing (DAST), container scanning and dependency scanning.

### Other GitLab Features

- Merge requests for reviewing and merging code.
- Issue tracking.
- Web IDE for editing code through a browser.
- Package and container registries.
- Project planning.
- Monitoring and deployment tools.
- Auto DevOps for automating parts of the development and delivery process.

---

## 3. Licensing

The main difference between GitHub and GitLab's licensing approaches is that the platforms themselves are licensed differently, while the software stored on either platform can have its own licence.

### GitHub

GitHub is a proprietary commercial service. Users can choose an open-source licence for code stored in their repositories, such as MIT or GPL.

### GitLab

GitLab has an open-source Community Edition and an Enterprise Edition. GitLab Community Edition is licensed under the **MIT License**, while Enterprise Edition has additional licensing restrictions. GitLab also provides a self-managed option, allowing organisations to install and manage their own GitLab instance.

### Main Licensing Difference

| GitHub | GitLab |
|---|---|
| GitHub's platform is a proprietary commercial service. | GitLab has an open-source Community Edition. |
| Users can place open-source projects on GitHub under licences such as MIT or GPL. | GitLab Community Edition is released under the MIT License. |
| GitHub provides free and paid commercial services. | GitLab provides free and paid subscription features and self-managed options. |

## 5. Features Unique to GitHub

### 1. GitHub Sponsors

GitHub Sponsors allows people to financially support open-source developers and projects through GitHub.

### 2. GitHub Codespaces

GitHub Codespaces provides cloud-based development environments that can be configured for a project, allowing developers to work on code without setting up the complete development environment locally.

### 3. GitHub Discussions

GitHub Discussions provides a dedicated area where communities can ask questions, share ideas and discuss projects without treating every conversation as an issue.

---

## 6. Features Unique to GitLab

### 1. Auto DevOps

GitLab Auto DevOps provides predefined automation and best practices to help teams implement CI/CD and move software through the development lifecycle.

### 2. Integrated DevSecOps

GitLab places development, security and operations tools together in one platform. It includes security features such as SAST, DAST, container scanning and dependency scanning.

### 3. Self-Managed Deployment

GitLab can be installed and managed on an organisation's own infrastructure. This gives organisations greater control over where their GitLab instance and project data are hosted.

## 8. Similarities

GitHub and GitLab are similar because both:

1. Use Git for version control.
2. Provide repositories for storing source code.
3. Allow developers to collaborate.
4. Provide branching and code-review functionality.
5. Provide issue/task management.
6. Support automation and CI/CD.
7. Can be used by individuals, teams and organisations.

---

## 9. Differences

The major differences are:

1. **Licensing:** GitLab provides an open-source Community Edition, while GitHub's platform is a proprietary commercial service.
2. **Development Approach:** GitLab focuses strongly on providing an integrated DevSecOps lifecycle in one platform.
3. **Community Features:** GitHub has features such as GitHub Sponsors and GitHub Discussions.
4. **Self-Management:** GitLab provides self-managed deployment options.
5. **Automation:** GitHub uses GitHub Actions, while GitLab provides GitLab CI/CD and Auto DevOps.

---

## 10. Conclusion

GitHub and GitLab are both powerful platforms for software development and collaboration. They provide many of the same fundamental features, including Git repositories, version control, branching, code review, issue tracking and CI/CD.

GitHub is widely used for software collaboration and open-source communities and provides features such as Pull Requests, GitHub Actions, Codespaces, Discussions and Sponsors.

GitLab provides a more integrated DevSecOps approach, combining source-code management, CI/CD, security, deployment and monitoring tools in one platform.

The biggest licensing distinction is that GitLab provides an open-source Community Edition under the MIT License, while GitHub operates its platform as a proprietary commercial service.

**Overall, both platforms are suitable for software development, but GitHub is particularly strong in developer and community collaboration, while GitLab is particularly strong in integrated DevSecOps and self-managed software development environments.**
